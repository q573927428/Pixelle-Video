# 数字人视频字幕功能方案

## 1. 背景

当前数字人（Digital Human）视频生成流程：

```
角色图片 + 商品图(可选) + 口播文案
        ↓
    TTS 生成音频 (克隆声音 / 内置语音)
        ↓
    ComfyUI/API 工作流 → 口播视频 (final.mp4)
```

**现有问题：** 生成的视频 **没有任何字幕（subtitle/CC）**。用户需要通过额外的后期工具手动加字幕，效率低且样式难以统一。

**需求：**
1. 生成的视频可以自动加字幕
2. 字幕样式可控（文字大小、颜色、X/Y 轴位置、宽度、文字背景颜色、填充 padding、圆角 border-radius、透明度 opacity）
3. 字幕预览与实际生成效果一致
4. 字幕功能可以开关

---

## 2. 架构设计

### 2.1 字幕生成流程

```
口播文案 (goods_text / generated_text)
        ↓
  字幕时间戳生成 (基于音频时长 + 文案分段)
        ↓
  SRT/ASS 字幕文件生成
        ↓
  FFmpeg drawtext/subtitles filter 将字幕烧录到视频
        ↓
  带字幕的最终视频 (final_subtitled.mp4)
```

## 3. 字幕配置参数 (SubtitleConfig)

```typescript
interface SubtitleConfig {
  enabled: boolean           // 字幕开关
  font_size: number          // 文字大小 (px)，默认 48
  font_color: string         // 文字颜色 (#RRGGBB)，默认 #FFFFFF
  font_family: string        // 字体，默认 "PingFang SC"
  position_x: number         // X 轴位置，0 = 居中，负数 = 偏左，正数 = 偏右
  position_y: number         // Y 轴位置，0 = 底部，负数 = 偏上，正数 = 偏下
  max_width: number          // 最大宽度 (px)，默认 900
  background_color: string   // 文字背景颜色 (#RRGGBB)，默认 #000000
  background_opacity: number  // 背景透明度 (0.0 - 1.0)，默认 0.6
  background_padding: string // 背景内边距，如 "10 20"
  background_radius: number  // 背景圆角 (px)，默认 8
}
```

### 3.1 默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| enabled | false | 默认关闭字幕 |
| font_size | 48 | 适配 1080P 视频 |
| font_color | #FFFFFF | 白色字体 |
| font_family | PingFang SC | 中文字体 |
| position_x | 0 | 水平居中 |
| position_y | 0 | 底部 |
| max_width | 900 | 1080P 视频约 83% 宽度 |
| background_color | #000000 | 黑色背景 |
| background_opacity | 0.6 | 半透明 |
| background_padding | "10 20" | 上下 10px，左右 20px |
| background_radius | 8 | 圆角 8px |

### 5.3 字幕烧录方法 (VideoService)

在 `pixelle_video/services/video.py` 新增 `burn_subtitle()` 方法：

```python
def burn_subtitle(
    self,
    video: str,
    subtitle_path: str,      # SRT 文件路径
    output: str,
    config: SubtitleConfig
) -> str:
    """
    将字幕烧录到视频中
    
    使用 FFmpeg subtitles filter + drawtext 实现样式控制。
    
    Args:
        video: 输入视频路径
        subtitle_path: SRT 字幕文件路径
        output: 输出视频路径
        config: 字幕样式配置
    """
    # 将 SubtitleConfig 转换为 ASS 风格的样式参数
    # 或使用 FFmpeg subtitles filter 的 options
    
    font_size = config.font_size
    font_color = config.font_color  # 转为 &HFFFFFF&
    position_y_offset = config.position_y
    max_width = config.max_width
    
    # 字幕背景使用 ASS 样式或 FFmpeg subtitles filter
    # FFmpeg subtitles filter 支持 SRT 基本样式
    # 更精细的样式需要生成 ASS 文件
    
    (
        ffmpeg
        .input(video)
        .output(
            output,
            vcodec='libx264',
            acodec='copy',  # 音频无需重新编码
            preset='medium',
            crf=23,
            # 使用 subtitles filter 添加字幕
            vf=f'subtitles={subtitle_path}'
        )
        .overwrite_output()
        .run()
    )
```

**更优方案 — 直接使用 FFmpeg drawtext filter + ASS 字幕：**

由于 SRT 格式对样式控制有限（不支持圆角、透明度等），**推荐使用 ASS（Advanced SubStation Alpha）格式** 或 **FFmpeg drawtext filter**：

#### 方案 A：ASS 字幕（推荐）

1. 首先生成 ASS 格式字幕文件（支持完整的样式控制）
2. 然后使用 `subtitles` filter 烧录

ASS 格式支持：
- 字体、字号、颜色
- 位置 (X/Y 坐标)
- 边框、阴影
- 背景色、透明度
- 圆角（通过矢量绘制形状实现）
- 行宽控制

#### 方案 B：drawtext filter

如果视频较短（单段文案），可以直接使用 `drawtext` filter，逐帧渲染。

```
ffmpeg -i input.mp4 -vf "drawtext=text='字幕内容':fontfile=font.ttf:fontsize=48:fontcolor=white:x=(w-text_w)/2:y=h-th-100:box=1:boxcolor=black@0.6:boxborderw=10" output.mp4
```

**局限性：** `drawtext` 的 box 背景不支持圆角、不支持多行自动换行、不支持长文本自动分段。

#### 方案 C：ASS + 背景形状（最终推荐）

**最终推荐方案** — 综合 ASS 的灵活性和背景形状需求：

1. 使用 Python 生成 ASS 文件
2. ASS 样式可以完全控制：字体、大小、颜色、位置、边框、阴影
3. 对于 **背景圆角** 和 **背景透明度**，在 ASS 中通过 `BorderStyle=4`（背景矩形）配合 `BackColour` 的 alpha 通道实现
4. 圆角效果通过 `\pos` 和 `\clip` 实现，或者留一个已知的限制说明——FFmpeg 的 ASS 渲染器（libass）不支持圆角矩形背景。**如果必须支持圆角，使用方案 B 的变体：先生成带透明背景的 PNG 字幕图像叠加层，再使用 overlay filter。**

### 5.4 最终推荐技术方案

由于需要同时支持：
- ✅ 背景颜色
- ✅ 背景透明度 (0~1)
- ✅ 背景内边距 (padding)
- ✅ 背景圆角 (border-radius)
- ✅ 文字大小/颜色
- ✅ X/Y 轴位置
- ✅ 最大宽度

**最佳方案：Python (Pillow) 生成字幕帧图像 + FFmpeg overlay 叠加**

```
1. 根据文案分段 + 音频时长 → 生成时间轴 SRT
2. 对于每段时间轴，使用 Pillow 绘制字幕图像：
   - 文字使用中文字体渲染
   - 支持圆角矩形背景（Pillow 可以直接绘制圆角矩形）
   - 支持透明度 (RGBA 模式)
   - 支持 padding
3. 使用 FFmpeg overlay filter 将字幕图像叠加到视频对应时间位置
4. 多段字幕 = 多个 overlay 叠加
```

**优势：**
- 完全支持所有样式需求（圆角、透明度、内边距等）
- 像素级精确控制
- 预览与实际完全一致
- 适用于任意视频分辨率

**缺点：**
- 渲染速度稍慢（但字幕图像较少，影响很小）

## 6. 字幕时间轴生成策略

### 6.1 单次模式

```
goods_text = "今天给大家介绍一款非常实用的产品。它采用了最新的科技。使用起来非常方便。"

1. 分段: ["今天给大家介绍一款非常实用的产品。", "它采用了最新的科技。", "使用起来非常方便。"]
2. 总音频时长: 15.2s
3. 每段时长: 15.2 / 3 ≈ 5.07s

SRT:
1
00:00:00,000 --> 00:00:05,070
今天给大家介绍一款非常实用的产品。

2
00:00:05,070 --> 00:00:10,140

```

字幕的 X/Y 位置需要基于视频实际分辨率计算。

需要将视频分辨率作为字幕服务的参数传入，以确保预览和最终视频的字幕样式一致。

## 11. 风险与注意事项

### 11.1 音频时长与字幕时间轴的偏差

TTS 生成的音频时长可能与预估有偏差。字幕时间轴使用实际音频时长（通过 FFmpeg probe 获取），确保 SRT 时间轴准确。

### 11.2 文案分段

对于长文案，需要智能分段。分段策略：
1. 按标点符号（。！？；）分割
2. 每段不超过 `max_chars_per_line` 个字
3. 超过限制的句子按字数切分

### 11.3 分辨率适配

所有位置参数都基于固定视频分辨率（1080×1920）计算。如果未来支持其他分辨率，需要做比例换算。

### 11.4 性能

字幕烧录需要重新编码视频（vcodec=libx264），会增加视频生成的时间。在进度回调中添加字幕阶段的进度更新。

### 11.5 圆角实现的限制

FFmpeg 的 ASS 字幕渲染器（libass）**不支持背景矩形的圆角**。如需圆角：
- 使用 Pillow 生成字幕帧图像（支持圆角矩形）
- 然后通过 FFmpeg overlay filter 叠加到视频上
- 这是唯一能够完全实现 CSS 级圆角效果的方式

## 13. 总结

| 需求 | 方案 |
|------|------|
| 字幕开关 | `enabled: boolean` |
| 文字大小 | ASS/Pillow `font_size` 参数 |
| 文字颜色 | `font_color` → ASS 或 Pillow 颜色 |
| X/Y 位置 | `position_x/y` → ASS `\pos` 或 Pillow 坐标 |
| 字幕宽度 | `max_width` → 控制每行最大宽度 |
| 背景颜色 | `background_color` → 背景矩形颜色 |
| 背景透明度 | `background_opacity` → RGBA alpha |
| 背景内边距 | `background_padding` → 背景矩形扩展 |
| 背景圆角 | Pillow 圆角矩形 → overlay 叠加 |
| 预览一致 | 同一套渲染逻辑、同一分辨率 |
| 性能 | 字幕帧数量 = 分段数（通常 < 10），性能开销极小 |
