# 📤 短视频平台自动发布功能设计方案

> 版本：v1.0  
> 日期：2026-07-01  
> 状态：草案 / 待评审  
> 目标：为 Pixelle-Video 增加一键分发到抖音、快手、小红书、视频号的功能

---

## 1. 背景与目标

### 1.1 现状

`PublishVideoDialog.vue` 已实现以下功能：

- ✅ 视频预览（URL 播放）
- ✅ 视频第一帧自动截取封面（竖屏 3:4 + 横屏 4:3）
- ✅ 标题 / 文案 / 话题标签编辑
- ✅ AI 一键生成标题 + 话题（调用 `/api/content/publish-prepare`）
- ✅ 4 个平台选择按钮（抖音、快手、小红书、视频号）
- ❌ **实际发布功能完全缺失** — `handlePublish()` 仅 emit 事件，无真实发布逻辑

### 1.2 目标

实现将视频**自动分发**到国内主流短视频平台的完整链路：

```
用户点击"发布" → 后台打开浏览器 → 自动登录平台 →
上传视频 → 填写标题/文案/话题 → 设置封面 → 点击发布
```

### 1.3 约束与假设

- 国内主流短视频平台**均未提供公开的开放上传 API**
- 唯一可行方案：**浏览器自动化（Playwright）** 模拟人工操作
- 需用户至少**扫码登录一次**，之后可复用 Cookie
- 平台 DOM 结构可能变化，需模块化设计便于维护
- 部署需要服务端能运行 Chromium（Linux 需安装依赖）

## 2. 技术选型

### 2.1 浏览器自动化引擎对比

| 工具 | 评分 | 优点 | 缺点 |
|------|------|------|------|
| **Playwright** | ⭐⭐⭐⭐⭐ | 微软出品，原生 async/await 支持，自动等待，浏览器上下文隔离，支持多浏览器，强大的选择器引擎 | 安装包较大 (~100MB) |
| DrissionPage | ⭐⭐⭐⭐ | 专为国内网站优化，内置数据包模式，轻量 | 社区较小，异步支持弱 |
| Selenium | ⭐⭐⭐ | 最老牌，资料多 | API 老旧，慢，需额外 WebDriver |
| Puppeteer | ⭐⭐⭐ | Chrome 团队出品 | 仅支持 Chromium，无原生 async 优势 |

**结论：选型 Playwright**

### 2.2 WebSocket 实时通信

- 发布任务可能持续 30s ~ 5min（上传视频 + 平台处理）
- 前端需要实时获取进度反馈
- 使用 **WebSocket** 推送状态事件，而非轮询

### 2.3 Cookie 存储

- 平台登录态保存为浏览器 Cookie（JSON 格式）
- **AES 加密**后存储在数据库 `platform_accounts` 表
- 支持多用户多平台多账号

```
    └─ 8. 完成

    │
    ▼
```

## 4. 详细设计

### 4.1 数据库设计 — platform_accounts 表

```sql
CREATE TABLE platform_accounts (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id       INTEGER NOT NULL REFERENCES users(id),
    platform      VARCHAR(20) NOT NULL,   -- douyin | kuaishou | xiaohongshu | shipinhao
    account_name  VARCHAR(100),           -- 平台显示的用户名
    cookies_encrypted TEXT,               -- AES-GCM 加密后的 Cookie JSON
    status        VARCHAR(20) DEFAULT 'active',  -- active | expired | revoked
    last_used_at  TIMESTAMP,
    expires_at    TIMESTAMP,              -- Cookie 过期时间
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE(user_id, platform)
);
```

### 4.2 发布会话管理 (内存 + 可选持久化)

```python
@dataclass
class PublishSession:
    session_id: str
    user_id: int
    platform: str
    status: str  # pending | running | need_login | success | failed
    progress: float  # 0-100
    current_step: str  # launching | uploading | filling | cover | publishing | complete
    message: str
    platform_url: str  # 发布成功后的平台链接
    error: str
    created_at: float
    ws_connections: List[WebSocket]  # 可用于广播的 WebSocket 连接列表

# 全局会话管理器
class SessionManager:
    _sessions: Dict[str, PublishSession] = {}
    
    def create(self, user_id, platform) -> str: ...
    def get(self, session_id) -> PublishSession: ...
    def update_status(self, session_id, **kwargs): ...
    def broadcast(self, session_id, event: dict): ...
    def cleanup_expired(self): ...
```

### 4.3 发布器基类设计

```python
class BasePublisher(ABC):
    """所有平台发布器的抽象基类"""
    
    # 子类覆盖常量
    PLATFORM_NAME: str = ""
    CREATOR_URL: str = ""
    UPLOAD_URL: str = ""
    
    def __init__(self, session: PublishSession, browser: Browser):
        self.session = session
        self.browser = browser
        self.page: Page = None
        self.context: BrowserContext = None
    
    async def execute(self, params: PublishParams):
        """发布主流程（由子类实现）"""
        try:
            await self._on_start()
            await self._ensure_login()
            
            await self._step("uploading", 20)
            await self._upload_video(params.video_path)
            
            await self._step("filling", 50)
            await self._fill_metadata(params.title, params.text, params.topics)
            
            await self._step("cover", 70)
            await self._set_cover(params.portrait_cover, params.landscape_cover)
            
            await self._step("publishing", 85)
            await self._click_publish()
            
            await self._on_success()
        except Exception as e:
            await self._on_error(str(e))
    
    async def _ensure_login(self):
        """确保登录态有效"""
        cookies = await cookie_manager.load(self.session.user_id, self.PLATFORM_NAME)
        if cookies:
            await self.context.add_cookies(cookies)
            await self.page.goto(self.CREATOR_URL)
            if not await self._is_logged_in():
                cookies = None  # Cookie 已过期
        
        if not cookies:
            await self._do_login()  # 扫码登录
    
    async def _do_login(self):
        """子类实现各平台登录流程"""
        # 1. 跳转到登录页
        # 2. 获取二维码截图 → 推送前端
        # 3. 等待扫码完成
        raise NotImplementedError
    
    @abstractmethod
    async def _upload_video(self, video_path: str):
        """上传视频（各平台选择器不同）"""
        ...
    
    @abstractmethod
    async def _fill_metadata(self, title: str, text: str, topics: list):
        """填写标题、文案、话题"""
        ...
    
    @abstractmethod
    async def _set_cover(self, portrait: str, landscape: str):
        """设置竖屏、横屏封面"""
        ...
    
    @abstractmethod
    async def _click_publish(self):
        """点击发布按钮并等待成功"""
        ...
    
    async def _step(self, step_name: str, progress: float, message: str = ""):
        """更新进度并广播到前端"""
        self.session.current_step = step_name
        self.session.progress = progress
        self.session.message = message or step_name
        await self.session_manager.broadcast(self.session.session_id, {
            "type": "progress",
            "step": step_name,
            "progress": progress,
            "message": message,
            "platform_url": self.session.platform_url,
        })
```

### 4.4 各平台实现要点

#### 抖音 (douyin.com/creator)

| 步骤 | 选择器 / 操作策略 |
|------|------------------|
| 创作者入口 | `https://creator.douyin.com/creator-micro/content/upload` |
| 登录 | 二维码扫码登录（二维码元素 `.qrcode-img`） |
| Cookie 检测 | 访问创作者页，检测是否有 `.upload-container` 或 URL 包含 `/creator/` |
| 上传视频 | `<input type="file">` 设置为 files，等待上传进度条消失 |
| 标题 | `[placeholder*="标题"]` 或 `.upload-input` |
| 文案+话题 | `[placeholder*="文案"]`，话题追加在文案末尾 |
| 封面 | 点击"自定义封面"→ 上传图片 → 拖动选择区域 |
| 发布按钮 | `button:has-text("发布")` 或 `.publish-btn` |

#### 快手 (creator.kuaishou.com)

| 步骤 | 选择器 / 操作策略 |
|------|------------------|
| 创作者入口 | `https://creator.kuaishou.com/publish` |

#### 小红书 (creator.xiaohongshu.com)

| 步骤 | 选择器 / 操作策略 |
|------|------------------|
| 创作者入口 | `https://creator.xiaohongshu.com/publish/publish` |
| 登录 | 小红书 App 扫码（二维码刷新频繁） |

| 步骤 | 选择器 / 操作策略 |

| 上传视频 | 文件上传，视频号限制 < 1GB，时长 < 30min |
| 标题 | 视频号只有标题，无独立文案区 |
| 话题 | 在标题末尾追加 `#话题` |
| 封面 | 从视频中选帧，也支持上传自定义封面 |
| 发布 | `button:has-text("发表")` |

### 4.5 反检测策略

```python
# stealth.py — Playwright 反检测脚本

STEALTH_SCRIPT = """
// 覆盖 webdriver 属性
Object.defineProperty(navigator, 'webdriver', { get: () => false });

// 覆盖 plugins 和 mimeTypes
Object.defineProperty(navigator, 'plugins', {
    get: () => [1, 2, 3, 4, 5],
});

// 覆盖 languages
Object.defineProperty(navigator, 'languages', {
    get: () => ['zh-CN', 'zh'],
});

// 覆盖 chrome 对象
window.chrome = { runtime: {} };

// 覆盖 permissions
const originalQuery = window.navigator.permissions.query;
window.navigator.permissions.query = (parameters) => (
    parameters.name === 'notifications' ?
        Promise.resolve({ state: Notification.permission }) :
        originalQuery(parameters)
);
"""

async def create_stealth_context(browser: Browser) -> BrowserContext:
    """创建带有反检测配置的浏览器上下文"""
    context = await browser.new_context(
        viewport={"width": 1920, "height": 1080},
        user_agent=(
            "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
            "AppleWebKit/537.36 (KHTML, like Gecko) "
            "Chrome/125.0.0.0 Safari/537.36"
        ),
        locale="zh-CN",
        timezone_id="Asia/Shanghai",
        geolocation={"longitude": 116.4, "latitude": 39.9},
        permissions=["geolocation"],
    )
    await context.add_init_script(STEALTH_SCRIPT)
    return context
```

```typescript

  "type": "need_login",

  "account_name": "用户昵称",

{
  "type": "complete",
```

## 5. API 接口设计

### 5.1 POST /api/publish/start — 启动发布

**Request:**
```json
{
  "platform": "douyin",
  "video_path": "output/20260701/xxx.mp4",
  "title": "精彩视频",
  "text": "这是一个用AI生成的视频...",
  "topics": ["#AI技术", "#数字人"],
  "portrait_cover": "data:image/png;base64,...",
  "landscape_cover": "data:image/png;base64,..."
}
```

**Response (200):**
```json
{
  "session_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "status": "pending",
  "message": "发布会话已创建"
}
```

**Error (400):** 平台不支持 / 参数错误 / 未安装 Playwright

### 5.2 GET /api/publish/status/{session_id} — 查询状态

**Response (200):**
```json
{
  "session_id": "a1b2c3d4...",
  "status": "running",
  "current_step": "uploading",
  "progress": 45,
  "message": "视频上传中 (45%)",
  "platform_url": "",
  "error": ""
}
```

### 5.3 WS /api/publish/ws/{session_id} — WebSocket 实时状态

- 建立连接后立即发送当前 Session 状态
- 后续自动推送所有状态变更事件（事件格式见 4.6 节）
- 支持自动重连（前端应实现指数退避重连策略）

**Request:**
```json
{
  "platform": "douyin",
  "cookies": [  // Playwright cookies 格式
```

**Response:**
```json
{
  "success": true,
  "message": "Cookie 保存成功，下次发布无需重新登录"

```

## 6. 配置项

在 `config.example.yaml` / `api/config.py` 中新增：

```yaml
publish:
  enabled: false                        # 是否启用发布功能（默认关闭需要手动开启）
  browser_engine: playwright            # 浏览器引擎
  headless: true                        # 是否无头模式
  browser_timeout: 300                  # 单次发布超时（秒）
  upload_timeout: 180                   # 上传超时（秒）
  max_retries: 3                        # 最大重试次数
  chromium_path: ""                     # Chromium 路径（留空自动下载）
  data_dir: "./browser_data"            # 浏览器用户数据目录
```

## 9. 风险与应对

| 风险 | 概率 | 影响 | 应对方案 |
|------|------|------|----------|
| 平台 DOM 结构变更 | 高 | 中 | 模块化设计 + 选择器配置文件化 + 启动时验证 |
| 检测到自动化操作被限制 | 中 | 中 | 反检测脚本 + 随机操作延时 + 真实设备指纹 |
| 二维码扫码超时 | 中 | 低 | WebSocket 推送 + 自动刷新 + 用户主动点击刷新 |
| 大视频上传超时 | 中 | 中 | 分片上传 + 合理超时 + 进度回调 |
| 无头模式在某些 Linux 上 crash | 低 | 高 | 使用 Playwright system deps 自动安装缺失库 |
| 多用户并发导致资源竞争 | 中 | 中 | 浏览器池 + 队列机制 |
| Cookie 泄露风险 | 低 | 高 | AES-GCM 加密 + 仅存储到数据库（不落日志） |
