# 定价改造方案（v6 - ZS币 + 按时长计费 + 邀请奖励）

## 1. 需求概述

去掉会员体系，引入 ZS 币作为平台代币，按视频时长扣费：

| 项目 | 规则 | 管理员可修改 |
|------|------|:-----------:|
| 充值比例 | 1 元人民币 = **100 ZS币** | ✅ |
| 每秒价格 | **5 ZS币/秒**（整数，无小数） | ✅ |
| 注册赠送 | 送 **600 ZS币**（整数，相当于 ¥6） | ✅ |
| 邀请奖励 | 邀请好友注册，邀请人得 **200 ZS币** | ✅ |
| 预扣校验 | 用户提交预估时长 → 验证余额 → 生成 → 按实际时长扣款 | — |
| 生成失败 | **全额退还**扣款 | — |

核心变更：
- **彻底取消 VIP / SVIP 会员体系**，所有用户统一规则
- 现有会员数据**全部清除重置**，所有用户回到同一起跑线
- 引入 **ZS币** 作为平台虚拟币，人民币 1:100 兑换
- 1 秒视频消耗 5 ZS币，时长精确到秒（**无小数**）
- ZS币余额为整数（**无小数**）
- 用户提交时输入预估时长 → 后端验证余额 → 预冻结 → 生成视频 → 按实际时长扣款
- 生成失败 → 全额退款
- **邀请注册奖励**：邀请人获得 ZS币奖励，金额可配置
- **无历史包袱**：不再区分老用户/新用户/年卡用户

---

## 2. 计费方式详解

### 2.1 币种换算

```
1 元人民币 = 100 ZS币
1 秒视频 = 5 ZS币
注册赠送 = 600 ZS币（可生成 120 秒视频）
邀请奖励 = 200 ZS币/人（推荐好友注册）
```

### 2.2 计费公式

```
预冻结金额（ZS币）= 预估时长（秒）× 5
实际扣费（ZS币）= 实际视频时长（秒，向上取整）× 5
若实际时长 ≠ 预估时长 → 多退少补（全部整数）
若生成失败 → 全额解冻
```

> 视频实际时长精确到秒，遇到小数秒**向上取整**（如 28.3 秒按 29 秒计费）。

### 2.3 示例

| 场景 | 预估时长 | 预冻结 | 实际时长 | 实际扣费 | 结果 |
|------|---------|--------|---------|---------|------|
| 正常 | 30秒 | 150 ZS币 | 28秒 | 140 ZS币 | 退还 10 ZS币 |
| 正常 | 30秒 | 150 ZS币 | 32秒 | 160 ZS币 | 补扣 10 ZS币 |
| 失败 | 30秒 | 150 ZS币 | — | 0 | 全额退还 150 ZS币 |

## 4. 完整扣费流程

```
用户提交生成请求（含预估时长，如 30 秒）
  │
  ├── 1. 计算预冻结金额 = 30 × 5 = 150 ZS币
  │
  ├── 2. 验证余额（原子操作）
  │     UPDATE users SET zs_balance = zs_balance - 150
  │     WHERE id = ? AND zs_balance >= 150
  │     ├── 余额不足 → 返回错误："ZS币不足，请充值"
  │     └── 余额充足 → 冻结成功，进入下一步
  │
  ├── 3. 写入 generation_log（status=frozen）
  │     INSERT INTO generation_log (task_id, user_id, estimated_seconds, frozen_zs, status)
  │     VALUES (?, ?, 30, 150, 'frozen')
  │
  ├── 4. 执行视频生成
  │     ├── 生成成功 → 获取实际时长（如 28 秒，向下取整）
  │     │               ├── 计算实际扣费 = 28 × 5 = 140 ZS币
  │     │               ├── 退还差额 = 150 - 140 = 10 ZS币
  │     │               │     UPDATE users SET zs_balance = zs_balance + 10
  │     │               │     WHERE id = ?
  │     │               ├── 更新 generation_log：
  │     │               │     actual_seconds=28, deducted_zs=140, status='deducted'
  │     │               └── 返回成功给前端
  │     │
  │     └── 生成失败 → 全额退款
  │                     ├── 退还全部冻结金额
  │                     │     UPDATE users SET zs_balance = zs_balance + 150
  │                     │     WHERE id = ?
  │                     ├── 更新 generation_log：status='refunded'
  │                     └── 返回错误给前端
  │
  └── 5. 前端展示：实际扣费、本次余额变动
```

### 4.1 关键代码实现

```python
# api/auth/dependencies.py —— 扣费核心逻辑

async def freeze_balance(user_id: int, estimated_seconds: int) -> tuple[bool, int, str]:
    """
    预冻结余额。
    返回 (成功?, 冻结金额, 消息)
    """
    zs_per_sec = int(await get_sys_config("zs_per_second", "5"))
    frozen = estimated_seconds * zs_per_sec   # 整数，无需 round
    
    affected = await Database.execute(
        "UPDATE users SET zs_balance = zs_balance - %s WHERE id = %s AND zs_balance >= %s",
        (frozen, user_id, frozen)
    )
    if affected > 0:
        return True, frozen, ""
    else:
        row = await Database.fetchone(
            "SELECT zs_balance FROM users WHERE id = %s", (user_id,)
        )
        balance = row["zs_balance"] if row else 0
        return False, 0, f"ZS币不足（当前 {balance}），需要 {frozen}，请充值"


async def settle_generation(task_id: str, user_id: int, frozen_zs: int,
                            actual_seconds: int, success: bool):
    """
    结算生成任务：
    - 成功：按实际时长扣费，退还差额
    - 失败：全额退款
    """
    if not success:
        await Database.execute(
            "UPDATE users SET zs_balance = zs_balance + %s WHERE id = %s",
            (frozen_zs, user_id)
        )
        await Database.execute(
            "UPDATE generation_log SET status = 'refunded', updated_at = NOW() "
            "WHERE task_id = %s", (task_id,)
        )
        return
    
    zs_per_sec = int(await get_sys_config("zs_per_second", "5"))
    actual_cost = actual_seconds * zs_per_sec
    refund = frozen_zs - actual_cost
    
    if refund > 0:
        await Database.execute(
            "UPDATE users SET zs_balance = zs_balance + %s WHERE id = %s",
            (refund, user_id)
        )
    elif refund < 0:
        affected = await Database.execute(
            "UPDATE users SET zs_balance = zs_balance + %s WHERE id = %s AND zs_balance >= %s",
            (refund, user_id, abs(refund))
        )
        if affected == 0:
            await Database.execute(
                "UPDATE generation_log SET status = 'abnormal', actual_seconds=%s, "
                "deducted_zs=%s, updated_at=NOW() WHERE task_id=%s",
                (actual_seconds, actual_cost, task_id)
            )
            return
    
    await Database.execute(
        "UPDATE generation_log SET actual_seconds=%s, deducted_zs=%s, "
        "status='deducted', updated_at=NOW() WHERE task_id=%s",
        (actual_seconds, actual_cost, task_id)
    )
```

```python
import secrets
import string

def generate_invite_code(length=8):
    """生成唯一邀请码（字母+数字）"""
    chars = string.ascii_uppercase + string.digits
    return ''.join(secrets.choice(chars) for _ in range(length))
```

#### 5.3.3 注册时处理邀请奖励

```python
async def handle_invite_reward(invite_code: str, new_user_id: int):
    """
    处理邀请注册奖励：
    1. 根据 invite_code 找到邀请人
    2. 给邀请人发放 ZS币 奖励
    3. 记录邀请日志
    """
    if not invite_code:
        return
    
    # 查找邀请人
    inviter = await Database.fetchone(
        "SELECT id, username FROM users WHERE invite_code = %s", (invite_code,)
    )
    if not inviter:
        return  # 邀请码无效，忽略
    
    inviter_id = inviter["id"]
    
    # 防止自邀
    if inviter_id == new_user_id:
        return
    
    # 读取奖励金额
    reward = int(await get_sys_config("invite_bonus", "200"))
    
    # 给邀请人发放奖励
    await Database.execute(
        "UPDATE users SET zs_balance = zs_balance + %s WHERE id = %s",
        (reward, inviter_id)
    )
    
    # 更新新用户的 invited_by
    await Database.execute(
        "UPDATE users SET invited_by = %s WHERE id = %s",
        (inviter_id, new_user_id)
    )
    
    # 记录邀请日志
    await Database.execute(
        "INSERT INTO invite_log (inviter_id, invitee_id, reward_zs) VALUES (%s, %s, %s)",
        (inviter_id, new_user_id, reward)
    )
```

#### 5.3.4 注册完整流程

```python
# 用户注册
async def register(username, password, email, invite_code=None):
    # 1. 创建用户（生成唯一邀请码）
    user_invite_code = generate_invite_code()
    register_bonus = int(await get_sys_config("register_bonus", "600"))
    
    user_id = await Database.execute(
        "INSERT INTO users (username, password_hash, email, role, daily_limit, "
        "zs_balance, invite_code) VALUES (%s, %s, %s, 'normal', -1, %s, %s)",
        (username, password_hash, email, register_bonus, user_invite_code)
    )
    
    # 2. 处理邀请奖励
    if invite_code:
        await handle_invite_reward(invite_code, user_id)
    
    return user_id
```

## 9. 设计要点

### 9.1 全部整数

| 字段 | 类型 | 说明 |
|------|------|------|
| `zs_balance` | INT | 用户余额，无小数 |
| `zs_per_second` | 配置值（整数） | 每秒消耗 |
| `estimated_seconds` | INT | 预估时长 |
| `actual_seconds` | INT | 实际时长（向下取整） |
| `frozen_zs` / `deducted_zs` | INT | 扣费金额 |
| `invite_bonus` | 配置值（整数） | 邀请奖励 |

### 9.2 并发安全

```sql
-- 冻结（原子操作）
UPDATE users SET zs_balance = zs_balance - %s WHERE id = %s AND zs_balance >= %s
-- 退还
UPDATE users SET zs_balance = zs_balance + %s WHERE id = %s
-- 邀请奖励
UPDATE users SET zs_balance = zs_balance + %s WHERE id = %s
```

### 9.3 时长取整规则

- 用户输入：**整数秒**
- 视频实际时长：从音频读取后**向下取整到秒**
  - 例如 28.9 秒 → 28 秒（向下取整）
  - 这样用户实际支付 ≤ 实际生成时长，用户体验更好

### 9.4 所有用户统一重置

上线时执行：
```sql
UPDATE users SET 
    role = 'normal', 
    vip_expires_at = NULL, 
    daily_limit = -1,
    zs_balance = 0,
    invited_by = NULL,
    invite_code = NULL
WHERE role IN ('vip', 'svip');
```

- **不再区分老用户/新用户/年卡用户**
- 所有用户统一通过注册赠送、邀请奖励或充值获得 ZS币

### 9.5 邀请奖励防刷

- 每人只能被邀请一次（`invited_by` 唯一）
- 不能自己邀请自己（`inviter_id != new_user_id`）
- 邀请码无效则静默忽略，不报错
- 管理员可调整 `invite_bonus` 控制奖励力度
